# 穿搭单品提取 (OutfitExtractionTab) 布局调整计划

## 概述

重构 `Cyzx4/components/OutfitExtractionTab.tsx` 组件的布局，优化模型选择、比例/分辨率控制、元素排除方式和单品提取逻辑。

## 源码文件

- **主文件**: `Cyzx4/components/OutfitExtractionTab.tsx`（657行）
- **类型定义**: `Cyzx4/types.ts`（AspectRatio, ImageResolution）
- **参考实现**: `ModelFactory/BatchPropsModifierTab.tsx`（比例/分辨率/模型选择器的UI参考）

## 实现步骤

### 步骤 1: 将模型选择器从头部分离，移至上传图片区域下方

**当前状态**: 模型选择器（Banana 2 / Banana Pro / GPT Image 2）在页面 Header 的右上角。

**目标**: 
- 从 Header 中移除模型选择器
- 在图片上传区域（Upload Area）下方，新增一个独立的 "图像模型与设置" 卡片区域
- 模型选择器采用类似 `BatchPropsModifierTab` 的卡片式3列网格布局
- 同时在此区域添加比例选择器和分辨率选择器

**具体改动**:
1. 从 Header 的 `flex items-center justify-between` 中移除右侧模型选择按钮组
2. 在图片上传区域 `</div>` 之后、"要去除的元素" 之前，插入新的设置卡片

### 步骤 2: 添加比例和分辨率选择器

**当前状态**: 组件中没有比例/分辨率选择UI，`extractSingleItem` 函数硬编码使用 `AspectRatio.SQUARE` 和 `ImageResolution.RES_2K`。

**目标**:
- 新增两个 state: `selectedRatio`（默认 `AspectRatio.SQUARE` / `1:1`）和 `selectedResolution`（默认 `ImageResolution.RES_2K` / `2K`）
- 在模型设置卡片中添加上下文相关的比例选项（1:1, 3:4, 2:3, 4:5, 9:16）
- 添加分辨率选项（2K, 4K）
- 将这些值传入 `generateImageToImage` 调用，替换硬编码值

**具体改动**:
1. 新增 state: `const [selectedRatio, setSelectedRatio] = useState<AspectRatio>(AspectRatio.SQUARE);`
2. 新增 state: `const [selectedResolution, setSelectedResolution] = useState<ImageResolution>(ImageResolution.RES_2K);`
3. 在设置卡片中渲染比例和分辨率选择按钮
4. 修改 `extractSingleItem` 调用，使用 `selectedRatio` 和 `selectedResolution`

### 步骤 3: 将"要去除的元素"从 textarea 改为标签按钮

**当前状态**: `removeElements` 是一个 textarea 输入框，用户手动输入要排除的内容。

**目标**:
- 将 `removeElements: string` 改为基于标签的多选模式
- 预定义可排除的元素标签，默认选中：**人物**、**上衣**、**衣服**
- 用户点击标签切换选中/取消状态
- 生成 prompt 时，将所有选中标签的名称拼接为排除指令

**具体改动**:
1. 新增常量 `REMOVE_TAGS` 数组：
   ```ts
   const REMOVE_TAGS = [
     { id: 'person', label: '人物', default: true },
     { id: 'top', label: '上衣', default: true },
     { id: 'clothes', label: '衣服', default: true },
     { id: 'hair', label: '头发' },
     { id: 'shoes', label: '鞋子' },
     { id: 'bag', label: '包包' },
     { id: 'hat', label: '帽子' },
     { id: 'background', label: '背景' },
   ];
   ```
2. 新增 state: `const [removeTags, setRemoveTags] = useState<Set<string>>(new Set(REMOVE_TAGS.filter(t => t.default).map(t => t.id)));`
3. 在 UI 中将 textarea 替换为标签按钮网格
4. 修改 `buildExtractionPrompt` 函数，从 `removeTags` 生成排除文案

### 步骤 4: 扩展"要提取的单品"预设列表

**当前状态**: 预设单品为：上衣、下装、连衣裙、外套、鞋子、包包、帽子、配饰

**目标**: 添加以下单品：
- **眼镜** (glasses)
- **耳环** (earrings)  
- **手环/手链** (bracelet)
- **项链** (necklace)
- 将原来的单一"配饰"拆分为具体类别，保留"其他配饰"

**具体改动**:
1. 更新 `PRESET_ITEMS` 数组：
   ```ts
   const PRESET_ITEMS = [
     { id: 'top', label: '上衣', icon: <Shirt /> },
     { id: 'bottom', label: '下装', icon: <Footprints /> },
     { id: 'dress', label: '连衣裙', icon: <ShoppingBag /> },
     { id: 'outerwear', label: '外套', icon: <ShoppingBag /> },
     { id: 'shoes', label: '鞋子', icon: <Footprints /> },
     { id: 'bag', label: '包包', icon: <ShoppingBag /> },
     { id: 'hat', label: '帽子', icon: <Crown /> },
     { id: 'glasses', label: '眼镜', icon: <Glasses /> },
     { id: 'earrings', label: '耳环', icon: <Gem /> },
     { id: 'bracelet', label: '手环', icon: <Watch /> },
     { id: 'necklace', label: '项链', icon: <Gem /> },
     { id: 'accessory', label: '其他配饰', icon: <Watch /> },
   ];
   ```
2. 从 lucide-react 导入新图标：`Glasses`, `Gem`

### 步骤 5: 提取结果跳过第一项

**当前状态**: 所有提取结果按顺序显示在右侧网格中。

**目标**: 第一项提取结果（最有可能是原图或冗余结果）不显示在结果网格中。网格只显示从第2项开始的结果。

**具体改动**:
1. 在结果渲染的 `items.map()` 前，使用 `items.slice(1)` 跳过第一项
2. 或者在 `items.filter()` 中过滤掉第一个结果
3. 更新结果计数显示以反映实际显示的项目数

### 步骤 6: 更新 `buildExtractionPrompt` 使用选中的比例

**当前状态**: prompt 末尾硬编码 `1:1 aspect ratio`

**目标**: prompt 中的输出比例应反映用户选择的 `selectedRatio`

**具体改动**:
1. 将 `selectedRatio` 传入 `buildExtractionPrompt` 或 `extractSingleItem`
2. 修改 prompt 末尾的 aspect ratio 文本为动态值

3. 验证分辨率选择器默认选中 2K，切换后正确传入 API
4. 验证排除元素标签默认选中 "人物"、"上衣"、"衣服"
5. 验证点击标签可切换选中状态

## 风险

- **低风险**: 所有改动集中在一个组件文件内，不影响其他功能
- **API兼容**: AspectRatio 和 ImageResolution 的枚举值保持不变，API 调用兼容
- **已有功能**: 提取逻辑核心不变，仅调整 UI 布局和 prompt 文本
