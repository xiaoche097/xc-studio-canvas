# Gray mannequin selector assets

Created with the built-in imagegen tool from the corresponding original PNGs.
Original files are retained. These assets are UI-only and are never sent to model generation.

Outputs: `scopes-mannequin.png`, `photography-mannequin.png`, `actions-mannequin.png`.

Prompt template (substitute the group name and grid):

Edit this {group} UI selection sprite sheet. Preserve exactly the original square canvas and equal {grid} grid, cell order, framing, poses, clothing, background and lighting differences. Replace EVERY person with a neutral matte gray display mannequin with a smooth featureless oval head: absolutely no eyes, eyebrows, nose, mouth, human facial details or hair. All exposed body parts matte gray. Preserve ears and hands as neutral mannequin anatomy for the detail crop. Keep clothing neutral grayscale. Preserve the background colors and lighting differences for photography styles. For actions preserve all 9 poses and stool, all limbs visible. No text, no borders. This is a production UI sprite sheet.

Groups: scopes uses 2x2; photography and actions use 3x3.
