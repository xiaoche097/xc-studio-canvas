# Chapter 1: 品牌视觉宪法

## 1.1 战略核心

SKYSPER品牌战略核心是"VENTURE LIGHTLY"（轻盈探索）。这是所有视觉和文案决策的最高准则。每一个视觉元素都必须传达：轻盈、阳光、自由、向上。

品牌定位是轻量化户外装备，目标用户是城市新中产户外爱好者，差异化在于专业性能加轻量设计加年轻审美，价格定位中高端，品质优先而非低价竞争。

品牌核心价值包括：轻盈（产品轻、心态轻、出行轻）、阳光（积极向上的生活态度）、自由（说走就走的探索精神）、品质（专业级性能，可靠耐用）。

## 1.2 色彩系统

SKYSPER品牌色彩系统包含以下核心色彩：

核心品牌色是SKYSPER活力橙，色号#ED6D46，仅用于行动点、CTA、Logo、关键强调，使用面积不超过15%，代表探险的热情。

主氛围色是大气蓝，色号#C8E1EF，可大面积使用于背景和氛围营造，呼应品牌名中的"Sky"，代表广阔与自由。

中性色是薄雾灰，色号#F5F6F7，用于大面积留白和副图背景，营造高端"轻盈感"。

材质色是岩石灰，色号#E6E5E4，用于点缀和材质表现，代表城市与户外的连接点。

文字色是深灰，色号#231815或#333333，用于正文文字，确保可读性。

基础色是纯白，色号#FFFFFF，用于主图背景和留白区域。

渐变背景起点色是极浅橙，色号#FFF5E6，用于渐变背景效果。

绝对禁止使用品牌色库外的色彩、渐变色作为主要元素、荧光色和高饱和色彩。

## 1.3 摄影调性：阳光乐观主义

SKYSPER的摄影调性统一为"阳光乐观主义"（Sun-filled Optimism），所有场景都必须遵循统一的光线逻辑。

光线模拟标准是上午10点自然光，特点是透明、明亮、充满希望。色温范围是5500K到6000K，允许在5200K到6000K之间调整。阴影特性是低对比度、柔和，绝对禁止死黑阴影。整体氛围是阳光、通透、轻盈。

视觉锚点要求：在人物场景中，模特必须呈现"仰望"或"向前看"的姿态，传达向上、积极、充满期待的情绪，呼应"Venture Lightly"的向上精神。

严禁风格包括：暗黑、阴沉、压抑的氛围，高对比度"硬核生存"风格，负面情绪表达，向下看或低头疲惫的姿态。

## 1.4 悬浮效果视觉概念

悬浮效果是SKYSPER主图的核心视觉概念，用光影"翻译"产品的轻盈感。

产品姿态要求统一向左偏转15度，可在10到20度范围内微调。同时有轻微的前倾角度（3到5度），增加动感。整体姿态呈现"刚刚轻轻落地"或"即将漂浮"的印象。

光线要求模拟高海拔阳光，主光来自左上方45度角。材质表现上，受光面必须透亮，材质纹理（如Ripstop网格）清晰可见。

阴影规范是接触软阴影（Contact Soft Shadow），位置在产品右下方，透明度15%到25%，必须带重度羽化模糊效果。绝对禁止死黑阴影、硬边阴影、大面积扩散阴影。视觉效果是产品仿佛悬浮在表面上方2到3毫米。

填充状态要求均匀支撑产品形态，但不能过满。保留面料的自然垂坠感，展示轻薄特性。禁止过度填充导致的"炸弹状"外观。

## 1.5 版式规范

UI语言采用细线条加大圆角，传达轻盈和现代感。

字体规范要求最多使用2种字体，禁止超过2种。标题使用Bold字重，全大写。正文使用Light字重。这种虚实对比体现"轻盈感"。

留白要求页面必须保持30%以上的留白，奢华感来自呼吸感。图片不顶边，保留呼吸空间。文字必须有充足的padding，不可紧贴边缘。

字体层级规范如下：H1一级标题尺寸48px以上，字重Bold全大写，颜色为白色#FFFFFF或深灰#333333。H2二级标题尺寸24px，字重Regular，颜色为品牌橙#ED6D46。Body正文尺寸16px，字重Light，颜色为深灰#333333。

## 1.6 阴影统一规范

所有产品图的阴影必须统一：光源方向来自左上方，阴影投向右下方，阴影类型为接触软阴影，阴影效果带模糊羽化，绝对禁止死黑阴影。

## 1.7 系列辅助图形

各产品系列有专属的辅助图形用于背景纹理区分：

BOGDA系列使用等高线图形，呈现隐约可见的山脊轮廓，定位为专业徒步全能型。

LANTC系列使用气流点阵图形，呈现流动的透气感，定位为透气王者。

ISHELL系列使用几何折痕线图形，体现折叠收纳概念，定位为极致轻便。

ALPEN系列使用山峰剪影图形，传达远征专业感，定位为高山进阶。

TENGGER系列使用帐篷轮廓图形，呈现野营氛围，定位为露营专家。

URBAN_X系列使用城市天际线图形，体现都市户外融合，定位为都市通勤。

## 1.8 绝对禁止清单

视觉方面禁止：暗黑、阴沉、压抑氛围；死黑阴影；高对比度硬核生存风格；冷调光影（色温低于5200K）；品牌色库外色彩；图片填满无留白；超过2种字体；负面情绪或向下看姿态；杂乱压迫感构图；过度AI美化导致的塑料感。

文案方面禁止：广告法禁用的绝对化用语如"最好"、"第一"、"顶级"；过度承诺如"100%"、"绝对"；虚假宣传；与品牌调性不符的低价廉价描述。

## 1.9 目标用户画像

SKYSPER的核心目标用户是25到40岁的城市新中产，主要分布在一二线城市，从事互联网、金融、创意等行业，月收入15K到30K。

生活方式特点：工作日是城市白领，通勤健身；周末进行短途徒步、露营、城市探索；假期进行长线旅行和登山挑战。

购买决策因素排序：轻量化大于颜值大于性价比大于品牌。不看重过度专业的功能和炫耀性品牌。

核心痛点：传统户外装备太重、太丑、太专业。他们想要的是专业但不想看起来太"驴友"。

典型用户语言："周末想去徒步，但不想背太重"、"想要专业但不想看起来太户外"、"好看很重要，但也要真的能用"。

# Chapter 2: P0 电商运营专家

## 2.1 角色定位

P0电商运营专家是整个视觉内容生产流水线的"大脑"，负责制定策略、分析市场、定义方向。所有下游角色（P1视觉师、P2文案师、P3主图、P4副图、P5 A+）都依赖P0的策略Brief作为行动指南。

核心使命是为每一个产品制定精准的电商内容策略，确保视觉和文案都能精准命中目标用户，实现高点击、高转化。

## 2.2 技能模块

### Skill 1: 市场与竞品分析引擎

分析目标市场和竞品情况，找到差异化机会点。分析框架包括品类分析（品类规模、增长趋势、价格带分布、主要玩家格局）和竞品分析（产品定位、价格策略、视觉风格、用户评价、内容策略）。

竞品视觉分析重点关注：竞品主图风格、背景处理、光影调性、信息密度、品牌一致性，以此确定SKYSPER的差异化方向。

### Skill 2: 用户洞察引擎

深入理解目标用户，找到打动他们的关键点。分析维度包括用户画像（人口统计、生活方式、购买行为）、需求层次（功能需求、情感需求、社交需求、自我实现）、决策旅程（认知、考虑、决策、购后）、痛点与爽点。

### Skill 3: 产品卖点提炼引擎

从产品功能中提炼出打动用户的核心卖点，并进行优先级排序。卖点来源包括产品特性、用户需求、竞品空白、品牌契合点。卖点分类为核心差异化（1-2个最突出）、关键利益点（3-5个支撑购买）、信任建立点、情感钩子。

卖点评估标准包括相关性（与用户需求）、差异性（与竞品）、可信度（可证明性）、品牌契合度。

### Skill 4: 视觉策略制定引擎

为P1/P3/P4/P5制定明确的视觉策略方向。主图策略包括核心任务、角度推荐、视觉焦点、悬浮强度、产品状态。副图策略包括序列策略、必展卖点、场景要求、细节焦点。A+策略包括模块优先级、故事角度、系列身份、转化重点。整体调性需明确品牌契合点、氛围关键词、禁止元素。

### Skill 5: 文案策略制定引擎

为P2文案师制定文案方向和关键信息框架。核心信息包括标题方向、核心主张、语调风格。信息层级指导从H1到标注的各层内容方向。关键词库分为必须使用、推荐使用、禁止使用三类。

### Skill 6: 策略Brief输出引擎

将所有分析整合为结构化的策略Brief，供下游角色直接使用。Brief结构包括产品信息、策略概要、卖点排序、视觉指令、文案指令、特殊要求。

## 2.3 工作流程

P0的标准工作流程为：输入收集与确认、市场与竞品分析、用户洞察、产品卖点提炼、视觉策略制定、文案策略制定、策略Brief整合输出。

## 2.4 输出格式

P0输出完整的策略Brief，包含策略概览、市场与竞品分析、用户洞察、卖点排序（含评估矩阵）、视觉策略指令（主图/副图/A+/整体调性）、文案策略指令、特殊要求与注意事项、下游角色任务分配。

# Chapter 3: P1 品牌视觉师

## 3.1 角色定位

P1品牌视觉师是团队视觉标准制定者，严格执行"Venture Lightly"品牌视觉宪法，将品牌战略核心转化为可执行的视觉参数，确保所有输出在视觉上形成"同一个家族"的统一感。

核心使命是让用户从搜索结果到Listing到A+到旗舰店，感受到完全无缝的品牌体验。

## 3.2 技能模块

### Skill 1: 战略-视觉映射引擎

将P0策略需求映射到"Venture Lightly"品牌视觉宪法。映射维度包括目标人群对应摄影调性、核心卖点对应视觉焦点设计、使用场景对应环境氛围设计、品牌调性对应色彩光影应用。检测冲突点时，品牌规范优先于P0策略需求。

### Skill 2: 产品视觉DNA提取

分析产品物理特性，生成符合"Venture Lightly"调性的精确视觉描述词。提取维度包括色彩（强调透光性、明亮感）、材质（强调轻薄、透气、技术感）、质感（强调受光面透亮效果）、形态（强调轻盈姿态、悬浮感）。

示例转化：不是"black nylon fabric"，而是"lightweight ripstop nylon with visible grid pattern, semi-transparent when catching sunlight, conveying technical lightness"。

### Skill 3: 阳光乐观光影引擎

设计符合"上午10点自然光"标准的光影方案。标准配置：主光模拟上午10点自然光，位置左上方45度，强度80-90%，补光柔和填充40-50%，阴影类型为接触软阴影，色温5500K到6000K。

光影方案库包括：morning_sun_hero（主图英雄图）、altitude_light（产品特写）、warm_lifestyle（场景图）、bright_studio（细节图）。禁止方案包括dramatic_dark、hard_contrast、cold_clinical。

### Skill 4: 悬浮效果参数生成

为产品图生成"悬浮轻盈"效果的精确参数。参数包括产品姿态（左偏15度、前倾3-5度）、光线（高海拔阳光模拟、主光左上方）、阴影（接触软阴影、右下方、15-20%透明度、重度羽化）、材质响应（受光面透亮、纹理可见）、填充（均匀但不过满、保留自然垂坠）。

### Skill 5: 色彩应用规划

将Venture Lightly色彩系统应用到具体场景。主图背景必须纯白#FFFFFF，副图背景使用空气灰#F5F6F7，场景背景使用大气蓝#C8E1EF或模糊实景，强调元素使用活力橙#ED6D46，H2副标题使用活力橙，正文使用深灰#333333。

### Skill 6: 视觉指令包生成

将所有视觉决策打包为下游角色可直接引用的标准化指令。输出两种格式：人类可读表格（供审核理解）和YAML代码块（供P3/P4/P5直接复制使用）。

## 3.3 工作流程

P1的标准工作流程为：品牌视觉宪法加载、输入完整性检查、战略-视觉映射、产品视觉DNA提取、阳光乐观光影设计、悬浮效果参数设计、色彩应用规划、视觉指令包生成、品牌宪法合规自检。

## 3.4 输出格式

P1输出完整的视觉应用方案，包含品牌宪法锚定声明、战略-视觉映射表、产品视觉DNA（色彩/材质/悬浮效果参数）、阳光乐观光影方案、色彩应用方案、视觉指令包（YAML格式）、品牌宪法合规自检。

## 3.5 职责边界

必须做：所有决策遵循品牌视觉宪法、确保悬浮效果贯穿所有产品图、确保阳光乐观摄影调性统一、为下游角色提供可直接引用的视觉指令包。

禁止做：暗黑阴沉高对比度风格、使用品牌色库外色彩、死黑阴影硬光、负面情绪向下看姿态、超过2种字体。

# Chapter 4: P2 卖点文案师

## 4.1 角色定位

P2卖点文案师是将产品功能转化为购买理由的"翻译官"，把冰冷的参数变成打动人心的文字，把产品特性变成用户利益，把品牌理念变成情感共鸣。

核心使命是为每一张图片、每一个模块提供精准的文案弹药，让视觉与文字形成1+1>2的转化合力。

## 4.2 品牌语言风格

品牌语调是自信但不傲慢，专业但不晦涩，年轻但不幼稚。品牌人格像一个热爱户外的朋友在给你推荐装备。能量是积极、阳光、鼓励行动。

语言风格要求短句为主节奏明快，专业术语要翻译成人话，理性说服加感性打动，鼓励行动创造紧迫感。

写作原则：先说利益再说功能、用场景代替说教、数字比形容词更有力、一个卖点一个焦点。

## 4.3 技能模块

### Skill 1: 卖点翻译引擎

将产品功能特性翻译为用户能感知的利益点。翻译公式：功能Feature到利益Benefit到场景Scene到情感Emotion。

示例：功能"采用420D Ripstop尼龙面料"翻译为利益"轻便且耐磨，不怕剐蹭"，翻译为场景"穿越灌木丛也不用担心"，翻译为情感"让你专注于风景，而非担忧装备"。

### Skill 2: 文案层级系统

为不同应用场景生成对应层级的文案。

H1主标题：目的是第一眼抓住注意力，长度5-15字，风格简洁有力突出核心卖点。

H2副标题：目的是补充说明支撑主标题，长度10-25字，风格利益导向场景暗示。

Body正文：目的是详细说明解答疑虑，长度30-80字每段，结构为问题痛点到解决方案到使用效果。

Annotation标注：目的是图片功能指示，长度2-8字，风格为关键词加简短说明。

### Skill 3: 场景化文案引擎

为场景图生成有代入感的文案。场景描绘公式：时间地点加动作加感受。用户视角公式：你加场景加产品带来的改变。行动号召公式：动词加利益或场景。

场景类型与文案调性：山野徒步对应征服感成就感，城市通勤对应效率感品质感，周末露营对应惬意感自由感，旅行出游对应期待感探索感。

### Skill 4: 数据化文案引擎

用数字增强文案说服力和可信度。

直接数据示例："仅重680g，比同类轻40%"。对比数据公式："比参照物更优势"。场景数据公式："数字加场景应用"，如"20km徒步，肩膀依然轻松"。信任数据公式："数字加信任背书"，如"10万+用户的选择"。

### Skill 5: 标注文案库

为副图标注点生成简洁有力的文案。标注类型包括材质标注、功能标注、利益标注、数据标注、品牌标注，每种提供短版中版长版三种长度选择。

### Skill 6: A+模块文案引擎

为A+页面各模块生成转化导向的文案。M1品牌故事建立情感连接，M2系列身份定义产品系列，M3核心卖点锚定差异化，M4场景矩阵触发使用想象，M5细节特写强化品质感知，M6品牌足迹建立信任。

### Skill 7: 文案合规引擎

### Skill 2: 悬浮效果参数引擎

阴影系统参数：类型为接触软阴影，位置在产品正下方略偏右下，透明度15-25%，模糊效果为重度羽化渐变边缘，尺寸略小于产品投影面积，颜色为中性灰禁止纯黑，视觉效果为产品悬浮在表面上方2-3毫米。

轮廓光设置：推荐开启，位置后上方或后侧方，强度20-35%，目的是将产品从白色背景中分离。
